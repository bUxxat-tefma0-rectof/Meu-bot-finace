# 📁 Storage / Media

Diretório de armazenamento de mídia do sistema.

## Estrutura
- `products/` - Imagens dos produtos
- `categories/` - Imagens das categorias  
- `banners/` - Banners e campanhas
- `temp/` - Arquivos temporários
- `exports/` - Arquivos exportados
- `backups/` - Backups automáticos

## Importante
Este diretório é gerenciado automaticamente pelo sistema.
Não modifique os arquivos manualmente.
